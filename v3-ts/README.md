# ShopLite — v3-ts

Phiên bản TypeScript (Vite) của ShopLite.

## Chạy

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Cấu trúc

```
v3-ts/
├── index.html / product.html / cart.html
├── public/products.json
├── src/
│   ├── types.ts
│   ├── api.ts / cart.ts
│   ├── main.ts / product.ts / cart-page.ts
│   └── utils/
└── vite.config.ts
```
