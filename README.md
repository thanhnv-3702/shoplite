# ShopLite

Shop e-commerce. Mỗi thư mục là một phiên bản nâng dần của cùng một sản phẩm.

| Version | Stack | Ghi chú |
|---------|-------|--------|
| `v1-html/` | HTML, CSS | UI tĩnh |
| `v2-js/` | JavaScript | API, search, cart (VNĐ) |
| `v3-ts/` | TypeScript + Vite | Type-safe shop |
| `v4-react/` | React + Vite + Tailwind | Component, JSX, props |
| `v5-next/` | Next.js | *(sắp tới)* |

## API

- [DummyJSON](https://dummyjson.com)
- [Fake Store API](https://fakestoreapi.com)

## Setup

### v4-react

```bash
cd v4-react
npm install
npm run dev
```

### v3-ts

```bash
cd v3-ts
npm install
npm run dev
```

### v2-js

```bash
cd v2-js
npx serve .
```

### v1-html

```bash
cd v1-html
npx serve .
```
