# ShopLite — v1-html

Giao diện **tĩnh** (Module 1). Chưa có JavaScript.

## Chạy local

Mở `index.html` trực tiếp trên trình duyệt, hoặc:

```bash
npx serve .
```

## Tiến độ Module 1

| Ngày | Nội dung | Trạng thái |
|------|----------|------------|
| Day 1 | Semantic HTML + CSS nền + khung `index.html` | ✅ |
| Day 2 | Flexbox & Grid — lưới SP + `product.html` | ⏳ |
| Day 3 | Responsive, tokens, `cart.html`, Tailwind CDN | ⏳ |
